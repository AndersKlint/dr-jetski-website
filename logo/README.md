# Logo assets

The active site identity uses three SVGs:

| Version | Intended use | SVG |
| --- | --- | --- |
| Full logo | Main branding and larger presentations, preferably 480px wide or more | [Final master](dr-jetski-studios-logo.svg) |
| Compact wordmark | Headers and smaller placements, 192px wide or more; prefer 240px+ for the Studios signature | [Compact SVG](dr-jetski-studios-logo-compact.svg) |
| DRJ icon | Favicons, avatars, and square placements | [Icon SVG](dr-jetski-studios-icon.svg) |

The compact wordmark preserves the final letter shapes and colors, removes fine highlights/shading and wake streaks, and enlarges Studios by 25%. The DRJ icon combines coral Dr. and a yellow J in the studio's forward-leaning arcade lettering, above a turquoise wave with a white crest. Derivative SVGs include named Inkscape layers.

Use SVG for sharp rendering at any display density. The active SVGs have transparent backgrounds and are suitable for vector use.

For placements narrower than the compact wordmark's minimum size, use the DRJ icon rather than shrinking the full name further.

## Favicon and social metadata

The favicon is the DRJ icon SVG. PNG/ICO, apple-touch, and studio social-image fallbacks were removed: Apple touch icons and social-image clients do not support SVG, so no raster fallback is supplied for the studio mark. Descriptive metadata remains, and supplied project image metadata is unaffected.

`dr-jetski-studios-logo.png` remains in this folder as a source artifact; it is not part of the active site identity.
