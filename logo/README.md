# Logo assets

The live site identity is mid-review, main first:

| Version | Intended use | SVG |
| --- | --- | --- |
| Full logo | Main branding and larger presentations, preferably 480px wide or more | [Warm main](dr-jetski-studios-logo.svg) |
| Compact wordmark | Headers and smaller placements, 192px wide or more; prefer 240px+ for the Studios signature | [Archived colorful compact](alternative_colorful/dr-jetski-studios-logo-compact.svg) |
| DRJ icon | Favicons, avatars, and square placements | [Archived colorful icon](alternative_colorful/dr-jetski-studios-icon.svg) |

The warm main preserves the approved logo geometry and applies the copper/parchment/taupe pass: Dr `#B77B58`, Jetski `#E5D6B8`, outline `#1B1612`, trim/foam `#F4E8D3`, water `#8A7D68`/`#A28B6C`/`#6D614F`. Main-first review is pending; the compact and icon recolor waits for main approval, so the live compact and icon intentionally point at the archived colorful originals.

The full colorful suite is archived untouched in [alternative_colorful](alternative_colorful): [full logo](alternative_colorful/dr-jetski-studios-logo.svg), [compact wordmark](alternative_colorful/dr-jetski-studios-logo-compact.svg), [icon](alternative_colorful/dr-jetski-studios-icon.svg), and [source PNG](alternative_colorful/dr-jetski-studios-logo.png). The archived compact preserves the final letter shapes and colors, removes fine highlights/shading and wake streaks, and enlarges Studios by 25%. The archived DRJ icon combines coral Dr. and a yellow J in the studio's forward-leaning arcade lettering, above a turquoise wave with a white crest. Derivative SVGs include named Inkscape layers.

Use SVG for sharp rendering at any display density. The active SVGs have transparent backgrounds and are suitable for vector use.

For placements narrower than the compact wordmark's minimum size, use the DRJ icon rather than shrinking the full name further.

## Favicon and social metadata

The favicon is the DRJ icon SVG (currently the archived colorful icon). PNG/ICO, apple-touch, and studio social-image fallbacks were removed: Apple touch icons and social-image clients do not support SVG, so no raster fallback is supplied for the studio mark. Descriptive metadata remains, and supplied project image metadata is unaffected.
