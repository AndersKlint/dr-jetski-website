# Logo assets

## Which version to use

| Version | Intended use | SVG |
| --- | --- | --- |
| Full logo | Main branding and larger presentations, preferably 480px wide or more | [Final master](dr-jetski-studios-logo.svg) |
| Compact wordmark | Headers and smaller placements, 192px wide or more; prefer 240px+ for the Studios signature | [Compact SVG](dr-jetski-studios-logo-compact.svg) |
| DJ icon | Favicons, avatars, and square placements | [Icon SVG](dr-jetski-studios-icon.svg) |

[Preview the variants at their actual display sizes](logo-variants-preview.png).

The compact wordmark preserves the final letter shapes and colors, removes fine highlights/shading and wake streaks, and enlarges Studios by 25%. The icon combines the master artwork's D and J with a simplified wave. Both derivative SVGs include named Inkscape layers.

Use SVG for sharp rendering at any display density. All SVGs and the individual PNG exports have transparent backgrounds; the preview sheet demonstrates charcoal and light backgrounds.

## Icon exports

Square PNGs are named `dr-jetski-studios-icon-{size}.png`, at **16, 32, 48, 64, 128, 180, 256, and 512px**.

`favicon.ico` contains the 16px, 32px, and 48px renderings.

For placements narrower than the compact wordmark's minimum size, use the DJ icon rather than shrinking the full name further.
