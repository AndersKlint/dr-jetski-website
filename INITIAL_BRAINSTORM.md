Technical Notes:

Best framework is probably Astro - pragmatic, efficient, clean, cheap.

Small Files (CLI Tools, Dev Packages): You can store these directly inside the public folder of your Astro project. They will be bundled into your build and served over a global Content Delivery Network (CDN) automatically.
Large Files (VST Plugins, Games, App Binaries): Use external direct links as you suggested. For a professional finish, you can wrap them in nice visual CTA buttons. If you want a step up from Google Drive/Mega, look at Cloudflare R2, which offers 10GB of completely free object storage per month with zero egress bandwidth fees. This keeps downloads fast and completely free for you.

Do not pay $5/month for a VPS. Since your build output is just a folder of raw HTML, CSS, and JS, you can host your site for free with global edge performance:
• Cloudflare Pages (Highly Recommended): Unmatched speed, unlimited bandwidth, free custom domains, and zero cost for static sites. It plugs right into your GitHub repository and deploys every time you run git push.

Few projects so far, most unfinished. I deffer screenshots and stuff for later, so for that we use placeholders for now. Names are also not set in stone and can change, and some are unnamed. 1. HanScan - a phone app (currently only android, but its flutter so ios can be realesed) that uses paddle ocr v6 to perform offline accurate state of the art ocr of chinese characters. Is a camera screen and allows user to take pictures or from gallery. Displays translation of text as overlay on screen at real pisition on image. Can switch between hanzi mode (original chinese chars with a popup dict when tapped), pinyin mode (displays pinyin instead on overlay) and english translation mode. Targeted at both language learners (e.g. scan their textbook, use popup dict ) or travelers in china who can scan signs and menues etc, and get pinyin or english. 2. LaoZi AI Flashcards - Currently only targeted for chinese learning, but might be expanded to more languages. Its a spaced repetition app similar to anki, but polished and refined focused on pragmatism and productivity. The twist is taht it uses AI to generate flashcards from e.g. an image of a vocabulary list of a textbook. It generates detailed flashcards with descriptions and example sentences etc. Spaced repetition flashcard engine. Targeted at serious chinese language learners, e.g. ppl attending a chinese language course at uni. Available for both desktop and phone (no apple products yet tho, only android linux windows and web) 3. HanKan - yet another chinese learners app. This one is oth a simple text write, that lets us write text in a text document and switch to popup mode, where we can read our text with a popup dict. It also offers a much stronger feature that might be the main feature actually - users can open any pdf and we perform targeted ocr where we tap / mouse click to open a popup dict at the tapped position of the tapped word. 4. Paddle-my-pdf a CLI tool (might be expanded to user facing GUI app later) that uses paddle OCR to convert scanned PDFs to OCR pdfs - mainly targeted for asian languages due to paddle ocr is so good at that. Processes large pdfs and turns them into copyable and searchable by performing ocr and layering the results as text on the pdf. Desktop only for now. 5. Vocal aligner (name will change to a product name) - a VST3 / CLAP plugin for DAWs thats similar to vocaling - aligns a dub track to a guide track in timing. So users can sing multiple takes of something and stack vocals by aligning timing perfectly. Works on linux too, which no other such product does. 5. chinese_popup_dict - a flutter package that wraps any text widget to make it into a popup dict. pressing a chinese char opens a popup dict. 6. dart_paddle_ocr - flutter package that is a e2e inference engine for ocr, using paddleocr v6 model (v5 too, and is expandable to any paddle model). Excells at chinese and asian languages. Fully offline and on device. It's optimized and performant, and handles text direction and rotation of input image for best result. 7. WayToClip - gnome shell extension. Pragmatic and keyboard centric clipboard manager. A keyboard shortcut opens up a small window at the mouse cursor with clipboard history. User can select entries to paste quickly with number keys, arrow keys, or mouse. Supports search clipboard history and favorites as well, also images in clipboard. Also cna ignore passwords from keepass etc  if enabled by metadata. 8. WORLD-vocoder-vst (name will change) - a vst plugin that decompositions voices into components. We can control each component and a lot of other params and resynthesise the voice to be played in realtime as midi. First a processing of the voice stage to make it into components, then modifications and playback is realtime midi notes. Its like a vocal synth but very powerful and has a creative twist. Can be used to change a voice, make harmonies, as a vocoder ish by playing back the singing or voice in a specific midi note's pitch, or as a synthesiser with a voice as the base waveform, to create interesting and unique synth sounds or sfx (this is a pretty new project, very much WIP). 9. yt-clip-extractor - small desktop app that uses yt-dl to quickly download and cut a video between two timestamped youtube urls. 10. spotify-screensave - small desktop linux app that displays album artwork, song title, and artist name as a pretty screensaver of the current played song.
